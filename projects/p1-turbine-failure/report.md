# Wind Turbine Failure Prediction — Report

Generated by `src/train.py`. Costs assumed: £1,500 per wasted call-out,
£9,000 per missed failure.

## Baseline

Always predicting "no failure" is **84.5% accurate**. Every accuracy
figure below is judged against that number, and the failure rate is 15.5%.

## Leakage audit

- **maintenance_ticket_raised** already removed upstream (Block 1 notebook 02). It encoded the outcome: every URGENT ticket corresponded to a failure
- Checked 6 numeric features for implausible class separation (>3 standard deviations), which is the signature of a leak

## Model comparison

Five-fold cross-validated average precision — threshold-free, so the comparison is
fair across model families.

| model | avg_precision | sd |
|---|---|---|
| logistic regression | 0.502 | 0.039 |
| random forest | 0.478 | 0.028 |
| gradient boosting | 0.475 | 0.033 |
| baseline (majority class) | 0.155 | 0.000 |

Gap between the top two: **0.024**. Typical fold variation: **0.033**.

**The top two are NOT distinguishable on this data. Choose on interpretability and operating cost, not on the score.**

## The decision

Selected model: **logistic regression**, at a threshold of **0.55**.

At that threshold, on the held-out set:

- catches **63.1%** of failures (69 missed)
- raises **223** false alarms
- expected cost **£955,500** against
  £1,579,500 at the worst threshold on the grid

Note where the conventional 0.5 sits: cost
£969,000. It is a
convention inherited from balanced problems, not an answer.

## What would make me distrust this in six months

- The sensor fleet is recalibrated, shifting the vibration distribution
- The maintenance policy changes, which changes what "failure within 90 days" means
- Missingness stops being informative because the faulty sensors get replaced —
  the `vibration_missing` flag is predictive *because* sensors fail on shaking
  turbines, and that relationship is a property of the current hardware
- Input distributions drift far enough that the chosen threshold is no longer
  cost-optimal, even if the ranking still holds
