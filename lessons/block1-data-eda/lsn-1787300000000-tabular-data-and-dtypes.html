Tabular Data and the Lies dtypes Tell

Rows, columns, types — and why the type a column loaded as is your first diagnostic.

Most business machine learning is tabular: rows are things, columns are facts about them. It's the least glamorous data in AI and it remains where most real value sits — which is why the original syllabus opens here too.

The dtype is a diagnostic, not a detail

When pandas loads a CSV it infers a type per column. That inference is a free test result and most people skim past it. A column you expect to be numeric arriving as object means pandas found something it couldn't parse and fell back to text.

In the Block 1 dataset, operating_hours loads as object. The cause turns out to be thousands separators plus a stray hrs suffix on some rows — two different formatting problems in one column, which is exactly what happens when data is assembled from more than one system.

The habitRun df.dtypes immediately after loading, every time, and read it. Any numeric-looking column typed as object is a question you must answer before doing anything else. It takes ten seconds and routinely saves an afternoon.

The types you'll meet

int64 / float64
Numbers
Note that a column with any missing value becomes float, because NaN is a float. An integer column that arrives as float often just means 'has gaps'.
object
Usually strings
The catch-all. Also what a mixed-type column becomes, which is why it's worth investigating.
category
Repeated labels
Far less memory than object for low-cardinality columns, and it makes the intended set of values explicit.
datetime64
Real dates
Only if you asked for it. Dates loaded as strings sort alphabetically, which puts 2026-01 before 2025-12 — a silent and nasty bug.
bool
True/False
Becomes object the moment a missing value appears.

Units and names

A column called gearbox_temp tells you nothing about whether it holds Celsius or Fahrenheit. In the Block 1 data, two of four sites report Fahrenheit in that same column — undetectable from the name, obvious the moment you look at the range per site.

Names are not contractsColumn names are documentation written by someone who has since left. Verify the unit, the range, and the meaning against the actual values before trusting any of them. Renaming to gearbox_temp_c after you've confirmed it costs nothing and prevents the bug returning.

Sentinel values

Some systems write a placeholder rather than a null when a reading fails: 9999, -1, 0, 1900-01-01. These are missing values in disguise, and because they're numeric they silently pollute every statistic.

In the Block 1 data, 22 rotor-speed readings are exactly 9999.0. Left in place they drag the column mean from 14.4 to 53.3 — a nearly fourfold distortion from 22 rows in six thousand. The tell is a repeated, round, physically implausible value.
