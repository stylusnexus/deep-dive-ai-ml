Lesson 1 of 5

When the Input Is Not Text

Images and documents enter the same context window, cost tokens, and break the assumptions the rest of this course made about both.

Everything so far assumed text in and text out. A multimodal model takes an image and the interesting part is not that it can — it is that the image becomes tokens in the same window everything else lives in, and every cost, limit and failure mode this course has taught applies to it unchanged.

An image is a number of tokens

The model does not see pixels. An encoder turns the image into a sequence of vectors occupying positions in the context, exactly like words. That single fact carries most of the practical consequences, because it means an image is priced, budgeted and truncated like text.

Resolution is a token count
The dial nobody realises they are turning
Larger images become more tokens, usually by tiling — the image is cut into patches and each contributes. Sending a screenshot at full resolution when a downscaled one would do is the same mistake as retrieving twenty chunks when four would do, and it is less visible because nobody thinks of an image as a length.
Documents are often images
The expensive surprise
A scanned PDF is pictures of pages. Processing it multimodally costs image tokens per page, where extracting the text first costs a fraction. Which is correct depends on whether the layout carries meaning.
Position still applies
So caching still applies
Images sit in the prefix like anything else. An image early in a stable prompt caches; an image that changes per request invalidates everything after it, which is the rule from the caching lesson with a different payload.
Detail settings
A quality-cost dial, chosen once and forgotten
Providers expose a low or high detail mode that changes how finely the image is tiled. It is a real quality-cost trade and it is usually left at the default by people who would agonise over a chunk size.
Worth knowing

Everything this course taught about context cost applies to images, and people apply almost none of it.

Teams that carefully count tokens, cap retrieved chunks and worry about prompt caching will attach a full-resolution screenshot to every request without measuring what it costs. The habits do not transfer, because an image does not look like a length — but the context window does not care what the tokens were made of, and neither does the bill.

For exampleMeasure it once. Send the same request with and without the image, read the input token count, and you have the price of that image in the units everything else in this course is denominated in.

Extraction is often the better tool, and it is less interesting

Before sending a document to a multimodal model, ask whether the layout carries meaning. A form, a chart, a diagram or a signed page needs to be seen. A text report does not, and extracting its text costs a fraction of processing pictures of its pages. The multimodal route is more impressive and frequently the wrong answer, which is the same shape as the fine-tuning argument in Block 7.
